# 모바일 청첩장

## 실행 방법
1. 압축을 푼 뒤 `index.html`을 브라우저에서 엽니다.
2. 인터넷 연결이 있으면 웹폰트가 적용됩니다. 사진은 `assets` 폴더의 로컬 파일을 사용합니다.
3. 실제 배포 시에는 폴더 안의 파일 구조를 그대로 웹 호스팅에 올리면 됩니다.

## 파일 구성
- `index.html`: 페이지 내용과 구조
- `style.css`: 색상, 글꼴, 반응형 레이아웃
- `script.js`: 사진 확대 팝업, 계좌번호 복사 팝업
- `assets/`: 첨부 시안에서 추출한 사진 이미지

## 실제 정보로 바꾸기
`index.html`에서 예식 날짜, 이름, 주소, 계좌번호, 은행명을 수정하세요.
지도 링크는 현재 예시 장소 검색으로 연결됩니다. 실제 예식장 주소가 정해지면 Google Maps URL의 검색어를 교체하세요.
계좌번호 복사는 HTTPS 또는 localhost 환경에서 가장 안정적으로 동작합니다.
